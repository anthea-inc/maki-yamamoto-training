## 課題１

- 擬似要素とは何かについて調査し、以下の点を含めて説明してください。

- 擬似要素の基本的な概念
- 使用する際の構文

擬似要素とは、「::」２つのコロンから始まるセレクターにつけるキーワードのこと
擬似要素を使うと、特定の要素の「特定の部分」にスタイルを当てることができる

注意点：「要素の選択が終わったあと」に「擬似要素」は書くことができる
【記述不可】
p::before:hover {  
 color: pink;
}

【記述可】
p:hover::before {  
 color: pink;
}

## 課題 2

- 以下の擬似要素について調査し、それぞれの役割と使用例を説明してください。

- ::first-line
  役割：段落やブロック要素の最初の 1 行をスタイリングする

使用例 解説：
p 要素の最初の１行に文字の太さとテキストカラー青を適用

使用例：
【CSS】
p::first-line {
font-weight: bold;
color: blue;
}

- ::first-letter
  役割：段落やブロック要素の最初の文字をスタイリングする

使用例 解説：
p 要素の最初の文字のみ、フォントサイズとカラーを変更

使用例：
【CSS】
p::first-letter {
font-size: 2em;
color: red;
}

- ::before
  役割：要素の前にコンテンツを挿入してスタイリングする
  使用例 解説：
  h1 要素の前に「🔹」を追加

使用例：
【CSS】
h1::before {
content: "🔹 ";
}

- ::after
  役割：指定した要素の直後に追加の内容を挿入する

使用例 解説：
Hello の後に「World!」という青色のテキストを表示

使用例：
【CSS】
.example::after {
content: " World!";
color: blue;
}

- ::marker
  役割：リストアイテムのマーカー部分（例：箇条書きの点や番号）をカスタマイズする
  使用例 解説：
  リストのマーカーを赤色の矢印（→）に変更

使用例：
【CSS】
.custom-list li::marker {
color: red;
content: "→ ";
}

- ::selection
  役割：ユーザーが選択（ハイライト）した部分のスタイルを変更する

使用例 解説：
選択部分を黄色背景・黒文字にする

使用例：
【CSS】
::selection {
background: yellow;
color: black;
}

## 課題 3

- 上記で挙げられていない擬似要素を 3 つ調査し、以下の項目を含めて説明してください。

- 擬似要素の名前と基本的な機能
- どのような場面で活用できるか

::placeholder
基本機能：入力フィールド（<input> や <textarea>）のプレースホルダーにスタイルを適用
活用場面：フィールドのヒントテキストを目立たせる

::spelling-error
基本機能：スペルミスのある部分にスタイルを適用
活用場面：スペルミスをユーザーに明確に示す

::grammar-error
基本機能：文法エラーのある部分にスタイルを適用
活用場面：視覚的に区別するために、スペルミスとは異なるスタイル（赤い波線など）を設定する
