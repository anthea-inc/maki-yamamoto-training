「::first-line」：段落やブロック要素の最初の 1 行をスタイリング

最初の１行なので適用される
２行目なので適用されない
3行目なので適用されない


「::first-letter」：段落やブロック要素の最初の文字をスタイリング

最初の文字だけスタイルを適用

「::before」：要素の前にコンテンツを挿入してスタイリング

よくわからないマークを先頭につけた


「::after」：指定した要素の直後に追加の内容を挿入
