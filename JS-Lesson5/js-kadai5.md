# 課題 1

- 以下の用語を使用して、JavaScript における演算子の概念を説明してください。

・演算子
・単項演算子
・二項演算子
・オペランド

JavaScript における演算子とは、値（オペランド）に対して何らかの処理を行う記号またはキーワードのこと
演算子はオペランドの数によって、単項演算子や二項演算子に分類される

-- 単項演算子 --
被演算子が 1 つだけ出てくる演算子
num ++
被演算子：num
演算子：++

-- 二項演算子 --
被演算子が 2 つ出てくる演算子
１ + ２
被演算子：１、２
演算子：+

-- 三項演算子 --
被演算子が 3 つ出てくる演算子
a ? b : c
被演算子：a、b、c
演算子：?、:

メモ：三項演算子は、if 文を一文で書くときに使う
メモ：被演算子 ＝ 値 ＝ オペランド

# 課題 2

- 以下の二項演算子について調査し、それぞれの役割を説明してください。

-- 加算演算子（+） --
役割：数値同士を加算する

【例：index.js】
console.log(10 + 5); // 15
console.log(3.5 + 2.5); // 6

-- 文字列結合演算子（+） --
役割：文字列同士を結合する
→ 数値と文字列が混在する場合、数値が文字列に変換され、結合される

【例：index.js】
console.log("Hello" + " " + "World"); // "Hello World"
console.log("答え: " + 810); // "答え:810"

-- 減算演算子（-） --
役割：数値同士の減算を行う
→ 文字列として書かれた数値（“10” など）も自動的に数値に変換される

【例：index.js】
console.log(10 - 5); // 5
console.log("10" - "3"); // 7（文字列が数値に変換される）

-- 乗算演算子（＊） --
役割：数値同士の乗算を行う
→ 文字列として書かれた数値（“10” など）も自動的に数値に変換される

【例：index.js】
console.log(4 _ 3); // 12
console.log("6" _ "2"); // 12（文字列が数値に変換される）
console.log("6" \* "hello"); // NaN（文字列が数値に変換できないため）

-- 除算演算子（/） --
役割：数値の除算を行う
→ 文字列として書かれた数値（“10” など）も自動的に数値に変換される
→ 0 で割ると「Infinity」や「NaN」になる

【例：index.js】
console.log(10 / 2); // 5
console.log("12" / "3"); // 4（文字列が数値に変換される）
console.log(5 / 0); // Infinity（0 での除算）
console.log(0 / 0); // NaN（定義できない計算）

-- 剰余演算子（%） --
役割：除算の余り（剰余）を求める

【例：index.js】
console.log(10 % 3); // 1（10 ÷ 3 = 3 余り 1）
console.log(15 % 4); // 3（15 ÷ 4 = 3 余り 3）
console.log(9 % 2); // 1（奇数なら余りは 1）
console.log(8 % 2); // 0（偶数なら余りは 0）

-- べき乗演算子（＊＊） --
役割：指数計算（累乗）を行う

【例：index.js】
console.log(2 ** 3); // 8（2 × 2 × 2）
console.log(5 ** 2); // 25（5 × 5）
console.log(10 ** 0); // 1（任意の数の 0 乗は 1）
console.log(2 ** -1); // 0.5（負の指数は逆数）

注意メモ：JavaScript の二項演算子は、数値計算だけでなく、文字列の結合や暗黙的な型変換の影響もある

# 課題 3

- 以下の単項演算子について調査し、それぞれの役割を説明してください。

-- 単項加算演算子（+） --
役割：数値をそのまま返すか、数値に変換する

【例：index.js】
let str = "10";
let num = +str; // 文字列を数値に変換
console.log(num); // 10（number 型）

let bool = true;
console.log(+bool); // 1（true は 1 に変換される）

-- 単項減算演算子（-） --
役割：数値の符号を反転させる
→ 　単項加算演算子と同様に、非数値を数値に変換することもできる

【例：index.js】
let x = 5;
console.log(-x); // -5（符号を反転）

let str = "20";
console.log(-str); // -20（文字列を数値に変換して符号反転）

-- インクリメント演算子（++） --
役割：変数の値を１増やす
使用方法
前置（++x）：値を増やしてから返す
後置（x++）：値を返した後で増やす

【例：index.js】
let a = 10;
console.log(++a); // 11（前置：すぐに 1 増える）
console.log(a); // 11

let b = 10;
console.log(b++); // 10（後置：元の値を返してから 1 増える）
console.log(b); // 11

-- デクリメント演算子（--） --
役割：変数の値を１減らす
使用方法
前置（--x）：値を減らしてから返す
後置（x--）：値を返した後で減らす

【例：index.js】
let c = 5;
console.log(--c); // 4（前置：すぐに 1 減る）
console.log(c); // 4

let d = 5;
console.log(d--); // 5（後置：元の値を返してから 1 減る）
console.log(d); // 4
