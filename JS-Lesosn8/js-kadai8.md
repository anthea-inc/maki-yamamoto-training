# 課題 1

- while 文の基本構文を説明してください。
- 条件式が false になるまでループが続く仕組みや、無限ループを避けるための注意点について考察してください。

while 文は、条件式が true の間、繰り返し処理を実行し、false になるとループが終了する

-- 基本構文 --
while (条件式) {
// 繰り返し実行される処理
}

-- 条件式が false になるまでループが続く仕組み --

1. ループの開始時に 条件式を評価する
2. 条件式が true の場合、ブロック内のコードが実行される
3. 1 回の実行後、再度条件式を評価し、true ならもう一度実行、false ならループ終了

-- 無限ループを避けるための注意点 --
① 条件が false になるように値を変化させる
② 終了条件を正しく設定する
③ break を活用する
→ 意図しない無限ループに陥った場合でも、break を使って強制的にループを抜けることができる

# 課題 2

- do-while 文の基本構文を説明するとともに、while 文との違いについて解説してください。

  do-while 文は、最低 1 回は必ず実行されるループ処理
  この構文の特徴として、do ブロック内の処理が先に実行されてから while の条件判定が行われるため、
  条件が false であっても 最低 1 回は処理が実行されるのがポイント

-- 基本構文 --
do {
// 繰り返したい処理
} while (条件式);

【do-while 文と while 文の違い】
-- do-while 文 --
• 動作の流れ: ループ本体を先に実行し、その後で条件をチェックする
• 特徴: 条件に関わらず、ループ本体が必ず 1 回は実行される

-- while 文 --
• 動作の流れ: ループに入る前に条件をチェックする
• 特徴: 初回のループ開始時に条件が「false」であれば、ループ本体は一度も実行されない

# 課題 3

- for 文とは何かについて調査し、以下の点を含めて説明してください。
  ・初期化
  ・条件式
  ・更新式

for 文は、プログラミングにおいて繰り返し処理（ループ）を実行するための制御構造の一つ

1. 初期化
   → ループが開始される前に、一度だけ実行される処理。ループ変数の宣言や初期値の設定が行われる

2. 条件式
   → 各ループの反復ごとに評価される条件。この条件が true（または真）であれば、ループの本体が実行され、false（または偽）であればループが終了する

3. 更新式
   → 各反復の後に実行される処理

# 課題 4

- break 文の基本的な役割と、ループ内で使用した際の動作について説明してください。

ループ内での break 文の基本的な役割は、ループを早期に終了させること
通常、ループが終了する条件を満たすと、自動的に次の処理に進むが
break を使うとそのタイミングを手動で切り替える

- break 文を使用することで、どのような場合に処理の効率化やコードの可読性向上が期待できるかについて考察してください。

その後の繰り返しが不要な場合に break を使うことで無駄な処理を省ける
条件付きで明確にループを終了させるため、ネストされた条件を避け、コードが読みやすくなる

メモ：break（中断する）

# 課題 5

- continue 文の基本動作および、ループ内で「スキップ処理」を実現する方法を説明してください。

-- 基本動作 --
ループ（for や while など）の内部で continue 文が実行されると、その時点で現在の反復の残りの処理はすべてスキップされ、ループは次の反復に移る

-- スキップ処理を実現する方法 --
【index.js】
for (let i = 1; i <= 5; i++) {
if (i % 2 === 0) continue;
console.log(i);
}

-- コードの説明 --
ループの実行
→ for ループで変数 i が 1 から 5 までインクリメントされる

条件チェックとスキップ
→ if (i % 2 === 0) で i が偶数かどうかを判定する。偶数の場合は continue により、その後の console.log(i) をスキップして次の反復に進む

奇数の出力
→ 偶数ではない（奇数）時は、console.log(i) が実行され、奇数がコンソールに表示される

- continue 文の使用がコードの可読性にどのような影響を与えるか、また適切な利用場面について考察してください。

【continue 文の使用による影響】
メリット
・不要な入れ子の if 文を減らせる
・ある条件下でその後の処理をスキップするという意図が明確に伝わる

デメリット
・多用されると、どこで処理が中断されるのか把握しにくくなり、全体の流れが追いづらくなる

-- 適切な利用場面 --
ループの現在の反復処理を終了し、次の反復処理にスキップする

【index.js】
for (let i = 0; i < 10; i++) {
// 偶数の場合、残りのコードをスキップして次の反復処理へ
if (i % 2 === 0) {
continue;
}
console.log(i); // この行は i が奇数の場合にのみ実行される
}
