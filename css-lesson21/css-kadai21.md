## 課題　１

- 詳細度とは何かについて調査し、以下の点を含めて説明してください。

詳細度の定義と計算方法
CSS における詳細度の役割
詳細度がスタイル適用順序に与える影響

【定義と役割】
詳細度 (specificity)とは、CSS ルールの優先順位を決定するための指標のこと
複数のルールが同じ要素に適用可能な場合、詳細度によってどのルールが優先されるかを決定する

【詳細度がスタイル適用順序に与える影響】

- 競合問題
  高い詳細度のセレクタが低い詳細度のセレクタを上書きするため、意図しないスタイルが適用される場合がある

- 保守性の低下
  詳細度が過度に高いセレクタを多用すると、スタイルのオーバーライドが難しくなり、コードが複雑になる

- 再利用性の制限
  特定の ID や深くネストしたセレクタは汎用性が低く、別のコンポーネントで再利用しにくくなる

メモ：
「オーバーライド」とは、既存の CSS ルールを新しいルールで上書きすることを指す
あるスタイルが適用されている要素に対して、さらに優先度の高いルールを指定することで
元のスタイルを変更または無効化する操作のことをいう

(A, B, C,)
A: ID セレクターの数
B: クラスセレクター、属性セレクター、擬似クラスの数
C: 要素型セレクター、擬似要素の数

【詳細度の計算方法】

1. 最初に A の値を比較し、最も大きいセレクターのスタイルが優先される
2. A の値が同等のとき、次に B の値を比較し、最も大きいセレクターのスタイルが優先される
3. A と B の値が同等のとき、次に C の値を比較し、最も大きいセレクターのスタイルが優先される
4. A、B、C の値がすべて同等であれば、最後に書かれたセレクターのスタイルが優先される

メモ：
!important や インラインスタイルは、セレクターの詳細度とは別軸で優先順位が決まる
!important は最優先で、どんな詳細度よりも強く、さらにインラインスタイルよりも強い
インラインスタイル（style=""）は、詳細度の計算結果に関係なく、通常のCSSよりも優先される
ただし、同じプロパティに複数の !important がある場合は、詳細度の高い方が適用される

優先順位：
!important付きインラインスタイル > !important付き外部CSS > インラインスタイル > 詳細度が高いセレクター > 通常のCSS

全称セレクターは、特殊なセレクターであるため、詳細度の計算には関与しない

## 課題 2

- 以下の CSS セレクタについて、それぞれの詳細度を計算し、優先順位を判定してください。

属性セレクター（例：[type="text"]）
詳細度：0-1-0 → 10 ポイント

クラスセレクター（例：.my-class）
詳細度：0-1-0 → 10 ポイント

ID セレクター（例：#my-id）
詳細度：1-0-0 → 100 ポイント

要素型セレクター（例：div, h1）
詳細度：0-0-1 → 1 ポイント

インラインスタイル（例：style="color: red;"）
詳細度：1-0-0-0 → 1000 ポイント（最優先）

【優先順位のルール】

1. 「!important」が最優先
2. 詳細度が高いセレクター
3. 記述順（後に書かれた方が優先）

メモ：
「!important」は 乱用すると管理が難しくなり、意図しないスタイルの上書きを招くことがあるため
緊急時や特定のスタイルをどうしても強制したい場合に限定して使用する

## 課題 3

- 詳細度が一貫していない場合に発生する問題点と、その解決方法について説明してください。
  【問題点】

1. 詳細度の高いセレクタが低いセレクタを上書きしてしまい、意図したスタイルが適用されない
2. 詳細度が高いセレクタ（例：ネストの深いセレクタ）を多用すると、ブラウザのスタイル計算が遅くなる

【解決方法】

1. クラスセレクタを主体とし、ID セレクタやタグセレクタは使用を最小限にする
2. 「.menu-item」のようにシンプルなクラス名を使用し、.header .menu .item のような深いネストを避ける
