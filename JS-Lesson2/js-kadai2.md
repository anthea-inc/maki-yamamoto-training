# 課題 1

- プログラミングにおいて、変数はどのような役割を持つものか説明してください。
- JavaScript では変数を宣言する際に var/let/const という 3 つのキーワードを使用します。それぞれについて以下の観点で違いを説明してください。
  ・再宣言の可否
  ・再代入の可否

- var にはどのような問題点がありますか？具体的に説明してください。
- let/const はそれぞれどのような状況で使用するべきかを説明してください。

【変数】
データを格納し、それをプログラム内で再利用するための名前付きの記憶領域
変数を使うことで、値を動的に変更したり、計算や処理の結果を保持したりできる

【var、let、const の違い】
var：
再宣言　 ◯
再代入　 ◯
スコープ：関数スコープ

let：
再宣言　 ×
再代入　 ◯
スコープ：ブロックスコープ

const：
再宣言　 ×
再代入　 ×
スコープ：ブロックスコープ

【var の問題点】
・巻き上げ
・関数スコープ
・再宣言、再代入できてしまうこと

var は関数スコープのため、if や for の中で宣言してもブロック外からアクセス可能になり、意図しない動作を招くことがある

【let、const の使い分け】
let：値を変更する可能性がある変数
const：値を変更しない定数

メモ：デフォルトでは「const」を使い、必要に応じて「let」を使う

# 課題 2

- JavaScript において、変数名として使用可能なルールを説明してください。また、使用できないケースについても言及してください。
- JavaScript では、定数を大文字で表記する場合があります。この命名ルールの目的と、具体例を挙げて説明してください。

【変数名のルール】
使用可能なルール

1. 英字（A–Z, a–z）、数字（0–9）、アンダースコア（_）、ドル記号（$）
   → 変数名は英字、アンダースコア（_）、ドル記号（$）で始める必要がある（数字で始めることはできない）

2. 大文字と小文字は区別される
   → 「box01」と「Box01」は異なる変数としてみなされる

3. Unicode 文字の一部
   →JavaScript では Unicode に基づいた文字が使用できるため、日本語なども変数名に使える（非推奨）
   → 例: let 変数１ = "こんにちは";（動作するが、可読性の観点から避けるべき）

使用できないケース

1. 予約語（キーワード）
   →「let」「const」「function」「if」「return」などの JavaScript の予約語は変数名として使用できない

2. 特殊文字（例: @, #, - など）
   → 記号（!, @, #, -, +, . など）は変数名として使えません。
   → エラー例: let box1-1 = 10;

   【命名ルールの目的】
   その値が「変更されるべきではない（不変である）」ことを明確にするため

1.物理定数
const PI = 3.14159265359; //円周率
const GRAVITY = 9.81; // m/s² 　//重力加速度（地球上での重力）

2.エラーメッセージやフラグ
const ERROR_MESSAGE_INVALID_INPUT = "入力が無効です。"; //エラーメッセージとして固定のテキストを保持する
const FEATURE_FLAG_NEW_UI = true; //機能フラグ

メモ：
機能フラグ（Feature Flag）とは、ソフトウェア開発において特定の機能の有効・無効を制御するための仕組みのこと
これにより、コードをデプロイ（本番環境に展開）した後でも、特定のユーザーにのみ機能を提供したり、段階的にリリースしたりすることができる
