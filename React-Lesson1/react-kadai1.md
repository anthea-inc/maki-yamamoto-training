## 課題 1

- React とはどのようなライブラリか、その特徴や用途、開発におけるメリットを含めて説明してください。

React は、ユーザーインターフェース（UI）を構築するための JavaScript ライブラリ
Facebook（現 Meta）によって開発され、2013 年にオープンソースとして公開された

特徴

1. コンポーネントベース
   → UI を「部品（コンポーネント）」として分割して開発できる
   例えば、ボタンやナビゲーションバー、カードなどを独立した再利用可能な部品として定義し、それらを組み合わせて画面を作る

2. 宣言的（Declarative）な記述
   → 状態（State）に応じて「どう表示するか」を書く。状態が変わると、自動的に UI が更新される

【index.jsx】
function Hello({ name }) {
return <h1>Hello, {name}!</h1>;
}

3. 仮想 DOM（Virtual DOM）
   → UI の更新を効率よく行うために、実際の DOM のコピーをメモリ上に保持し、差分だけを更新する仕組み

4. JSX（JavaScript XML）
   → JavaScript の中に HTML のような構文を記述できる構文拡張。UI の構造を直感的に書けるのが魅力

【index.jsx】
const element = <h1>Hello, world!</h1>;

-- 開発におけるメリット --
再利用性：コンポーネント単位で再利用しやすく、保守性が高い
高速な UI 更新：仮想 DOM によって効率的に UI を更新できる
エコシステムが豊富：状態管理（Redux,Zustand）、ルーティング（React Router）などの周辺ツールが充実
コミュニティが活発：情報が豊富で、困ったときに解決策を見つけやすい
React Native に対応可能：Web とモバイルアプリの知識を共通化しやすい

---

メモ：
React のエコシステムとは？
React 自体は「UI を作るためのライブラリ」でしかないので、ルーティング（ページ遷移）や状態管理（データの保持と共有）といった機能は含まれていない
そのため、React の周りには、そういった不足を補う 周辺ライブラリ（エコシステム） が発展していて、組み合わせることで「アプリ全体の仕組み」を柔軟に構築できるようになっている

React Native とは？
React の思想（コンポーネント、JSX、状態管理など）を使って、iOS や Android 向けのネイティブアプリを開発できるフレームワーク。開発元が Facebook（現 Meta）のため、React 開発者にとってはとても馴染みやすい

## 課題 2

- CLI Tools としての Vite は何を提供しているのか、どのような特徴を持つのかについて説明してください。

Vite をインストールすると、vite コマンドが CLI ツールとして利用可能になる

-- 主なコマンド --
1. 開発サーバーの起動
→ vite

2. 本番用ビルドの生成
→ vite build

3. ビルド結果のローカルプレビュー
→　vite preview

4. 利用可能なオプション一覧を表示
→ vite --help

-- 特徴 --
1. 高速な起動と更新
→ 開発サーバーの起動が非常に高速で、コードの変更も即座に反映されるホットリロードが可能

2. フレームワークとの統合性
→ React、Vue、Svelte などのフレームワーク用テンプレートが公式で提供されている

3. プラグイン拡張が容易
→ Rollup ベースのプラグインシステムが使えるため、豊富なエコシステムとの連携も簡単

メモ：
Rollup とは？
Rollup は JavaScript モジュールを効率よくバンドルするためのビルドツール
Vite は本番ビルド（vite build）の際に Rollup を使う

Rollup プラグインの特徴
・JavaScript/TypeScript で記述
・公式プラグインが多数あり、独自プラグインも作成可能






---
メモ：
CLI Toolsとは？
「CLI Tools（コマンドラインインターフェースツール）」とは、コマンドライン（ターミナルやシェル）を通じて操作するツールのこと

Viteとは？
「Vite（ヴィート）」とは、フロントエンド開発をより快適・高速にするために登場したモダンなビルドツール／開発サーバー
