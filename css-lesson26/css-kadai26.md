# 課題１

- フレックスボックスとは何かについて調査し、以下の点を含めて説明してください。

・フレックスコンテナー
・フレックスアイテム

フレックスボックス（Flexbox）は、要素を効率的に配置・整列・分配するためのもの
特に、可変サイズのコンテンツを扱う際や、中央配置・均等配置などの調整を柔軟に行うのに適している
親要素（フレックスコンテナー）とその子要素（フレックスアイテム）の関係によってレイアウトを決定する

親要素に下記を指定
「display:flex;」・・・親要素がブロックレベル要素
「display:inline-flex;」親要素がインライン要素

フレックスボックスでできること
・要素の並び順を変える
・要素の折り返し方を決める
・要素の配置を決める
・要素の高さや幅を自由自在に指定する

# 課題 2

- 以下のフレックスコンテナーのプロパティについて調査し、それぞれの役割を説明してください。

・flex-direction
役割：フレックスコンテナー内のアイテムをどの方向に並べるかを決定する
メモ：主軸（main axis）を変更すると、それに応じてアイテムの配置が変わる

row
役割：フレックスアイテムを 横方向に配置する（→）（デフォルトの値）
メモ：主軸（main axis）は 水平方向（→）

column
役割：フレックスアイテムを 縦方向に配置する（↓）
メモ：主軸（main axis）は 垂直方向（↓）

row-reverse
役割：row の逆の順番 でフレックスアイテムを配置する（←）
メモ：主軸は 水平方向（→）のまま だが、順番が反転する

column-reverse
役割：「column」の逆の順番 でフレックスアイテムを配置する（↑）

・flex-wrap
役割：フレックスアイテムが 折り返し可能かどうかを制御する

nowrap
役割：折り返しなし（横一列固定）

wrap
役割：折り返しあり（親コンテナを超えると次の行に移動）（↓）

wrap-reverse
役割：フレックスアイテムを複数行に折り返す際に逆順で配置する（↑）

・flex-flow
役割：「flex-direction 」と「flex-wrap」を一括設定する

---

メモ：
「flex-direction: row;」と「flex-wrap: wrap;」を同時に指定したい場合

【CSS】
.container {
display: flex;
flex-flow: row wrap;
}

---

・justify-content
役割：フレックスコンテナ内での主軸（main axis）方向の揃え方を指定する（アイテムを主軸方向にどう並べるかを決める）

center
役割：中央寄せ

flex-start
役割：左寄せ（デフォルト）

flex-end
役割：右寄せ

space-around
役割：各アイテムの 左右に均等な間隔

space-between
役割：両端揃え（間隔均等）

space-evenly
役割：すべての間隔を均等に配置

・align-items
役割：Flexbox のコンテナ内で子要素（アイテム）を交差軸（デフォルトでは縦方向）に沿って揃える

center
役割：アイテムを交差軸の中央に配置する

flex-start
役割：アイテムを交差軸の開始位置（通常は上側）に配置する

flex-end
役割：アイテムを交差軸の終端（通常は下側）に配置する

stretch
役割：アイテムの高さ、または幅をコンテナの交差軸いっぱいに引き伸ばす（デフォルトの動作）
メモ：
「stretch」は主に高さを引き伸ばすが、状況によって幅にも影響する（Flexbox の方向次第）
アイテムの「height」（または width）が明示的に指定されていると「stretch」は効果を発揮しない

baseline
役割：フレックスコンテナ内のアイテムの テキストのベースラインを基準に整列させる
メモ：ベースライン（文字の下端が揃う基準線）

normal
役割：親要素の「align-items」のデフォルト値に従う
メモ：Flexbox の場合 → 「stretch」（デフォルトで子要素の高さが揃う）

・align-content
役割：複数行にわたるフレックスアイテムの配置を制御する

center
役割：フレックスコンテナ内でアイテムの行全体を中央揃えにする

stretch
役割：フレックスコンテナの高さいっぱいに各行を引き伸ばす（デフォルト）

flex-start
役割：フレックスコンテナの開始位置（上側）にアイテムの行を寄せる

flex-end
役割：フレックスコンテナの終了位置（下側）にアイテムの行を寄せる

space-around
役割：各行の周囲に均等な余白を持たせる

space-between
役割：各行の間に均等な間隔を作る（端の行はコンテナの端に揃えられる）

space-evenly
役割：すべての行の間隔を均等にする

メモ：
「align-content」はフレックスアイテムが複数行に分かれる場合にのみ有効になるので
「flex-wrap: wrap;」または「flex-wrap: wrap-reverse;」を設定する必要がある

# 課題 3

- 以下のフレックスアイテムのプロパティについて調査し、それぞれの役割を説明してください。

order
役割：フレックスコンテナ内でアイテムの表示順を変更する
メモ：デフォルト値は「0」で、数値が小さいほど先に配置され、大きいほど後に配置される。（負の値も設定可）

flex-grow
役割：全アイテムの flex-basis 合計値を引いた残りスペースを、各アイテムの flex-grow 値の比率で分配する

💡せいはさんレビューメモ
全フレックスアイテムのflex-basisの合計値を引いた残りスペース

メモ：
・デフォルト値「０」（余白を伸ばさない）
・「１またはそれ以上の数値」他の「flex-grow」の値と比率で余白を分配する
・「２以上」他のアイテムと比較して 2 倍、3 倍といった比率で伸びる

flex-shrink
役割：フレックスアイテムがフレックスコンテナ内で縮小する割合を制御する
メモ：
・デフォルト値「1」必要に応じて縮小される
・「０」縮小されない
・「１以上」他のアイテムよりも多く縮小する

flex-basis
役割：フレックスアイテムの初期サイズを指定する（コンテンツサイズとは無関係）
メモ：「０」を指定すると「flex-grow」の比率に従う

flex
役割：フレックスアイテムのサイズ調整を一括で指定する
メモ：
書き方
flex: <grow> <shrink> <basis>;

align-self
役割：個々のフレックスアイテムの垂直方向（交差軸）の配置を制御する
メモ：
auto（デフォルト）: align-items の値を継承
flex-start : 軸の開始側に揃える
flex-end : 軸の終了側に揃える
center : 軸の中央に揃える
baseline : テキストのベースラインに揃える
stretch : 高さを最大まで伸ばす
