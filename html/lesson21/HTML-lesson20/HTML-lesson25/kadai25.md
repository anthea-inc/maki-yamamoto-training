- `SVG`の定義と特徴について説明してください。

【定義】
SVG：Scalable Vector Graphics（スケーラブル・ベクター・グラフィックス）
W3C（World Wide Web Consortium）によって標準化されたグラフィック形式。
XML をベースにしたテキストフォーマットで、図形、パス、テキスト、画像を構成できる。
ベクター形式なので、ピクセルではなく、数式でグラフィックが定義されている。

【SVG の特徴】

1. XML 形式で記述されるため、テキストエディタで直接編集が可能でファイルサイズが小さい
2. css でのスタイルの適用が可能
3. DOM（Document Object Model）に統合されているため、JavaScript を使って動的に操作や変更が可能

---

メモ１：ベクター形式とは、画像をピクセル（点の集まり）ではなく、数式や幾何学的な情報で表現する形式を指します。この形式では、直線や曲線、形状、色などを数学的な計算で定義する

【ベクター形式の特徴】

1. 解像度に依存しない
2. 軽量なファイルサイズ
3. 編集が容易
4. 主に図形やイラストに適している

メモ２：XML（eXtensible Markup Language）は、データを構造化して記述するためのマークアップ言語

- `<svg>`タグの役割や、その具体的な用途について説明してください。

役割：SVG のグラフィックを定義する
用途：<svg>タグ内で以下のタグを使用することで、円、四角形、直線などの基本図形を描画することができる

円 (<circle>)
長方形 (<rect>)
線 (<line>)
多角形 (<polygon>)
パス (<path>): 自由な形状を描画

---

メモ：
<svg>タグの属性

width: 描画領域の幅を指定（例: width="500"）。
height: 描画領域の高さを指定（例: height="500"）。
viewBox: 描画内容の座標系を設定（例: viewBox="0 0 200 200"）。
xmlns: 名前空間を指定（通常 xmlns="http://www.w3.org/2000/svg"）。
fill: 塗りつぶしの色を指定
stroke: 線の色を指定

- `SVG`と`Canvas`の違いや、それぞれの適した利用シーンについて整理し、比較してください。
  【SVG と Canvas の違い】

描画方式
SVG：ベクターグラフィックス（形状やパスの集合）
Canvas：ラスタグラフィックス（ピクセルベース）

解像度の影響
SVG：解像度に依存しない（スケーラブル）
Canvas：解像度に依存する（ピクセルの集合）

DOM との連携
SVG：DOM 要素として扱われる
Canvas：描画結果は DOM の外部

【それぞれの適した利用シーン】

SVG を選ぶ場合

- 要素が少なく、再利用やスケーリングが重要な場合
- グラフィックスにイベント（クリック、ホバーなど）が必要な場合
- 高解像度やズームが必要なインタラクティブなチャートやダイアグラムを作る場合

Canvas を選ぶ場合

- リアルタイム描画やアニメーション（ゲームやシミュレーション）を実装する場合
- ピクセル単位の細かい操作が必要な場合（画像処理など）
- 多くの要素を描画する必要がある場合
