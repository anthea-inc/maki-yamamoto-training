- 以下の HTML タグについて、それぞれの目的と使用シーンを具体的な例を挙げて説明してください。
- `<video>`
  目的：Web ページで動画コンテンツを埋め込むために使用される
  使用シーン：製品やサービスのプロモーション動画を Web サイトに掲載。ニュースサイトで動画ニュースを配信。
  メモ：<track>タグ(字幕)を合わせて使用することで、アクセシビリティを向上する

- `<source>`
  目的：複数のフォーマットを指定して互換性を確保する
  使用シーン：複数のソースを指定する。軽量なフォーマットや低解像度の動画を指定してモバイルデバイス向けの最適化をする。
  メモ：<video>や<audio>タグ内で使用され、ブラウザが対応するフォーマットのメディアを自動的に選択して再生する

- `<track>`
  目的：動画や音声に字幕やキャプション、説明文、翻訳、チャプター情報などを提供する
  使用シーン：多言語対応の字幕、チャプター付きの動画
  メモ：<video>や<audio>タグと組み合わせて使用する

- `<audio>`
  目的：Web ページに音声コンテンツを埋め込む
  使用シーン：ウェブ上で音楽を再生するプレイヤー、発音練習やリスニング教材などの学習素材
  メモ：ユーザーが音声を再生・一時停止・音量調節するなどの操作が簡単にできる音声プレイヤーを提供する

### 課題２

- 以下の属性について、それぞれの目的と使用シーンを具体的な例を挙げて説明してください。
- `<video>`/`<audio>`
  　- `controls`
  目的：ユーザーにメディア（動画や音声）を操作するためのインターフェースを提供する
  使用シーン：動画や音声を埋め込む際に、手軽に標準 UI を提供したい場合

- `autoplay`
  目的：Web ページが読み込まれると同時にメディアを自動再生する
  使用シーン：音声ガイド、チュートリアル、プロモーション

注意点メモ：ほとんどのモダンブラウザ（例: Chrome、Firefox、Safari）では、音声付きの自動再生はブロックされることがあるため、muted 属性を追加して無音状態にすることで、動画は自動再生されやすくなる。

- `muted`
  目的：音声を無効化（ミュート）する
  使用シーン：モバイルユーザーへの配慮、広告やプロモーション動画

- `<source>`
  　- `src`
  目的：<source>タグ内で指定するメディアリソース（画像、音声、動画など）の URL を指定する
  使用シーン：フォールバックの提供（リソースが利用できない場合に、それを代替する別の選択肢を提供）
  メモ：<source>タグは、異なる形式や品質のメディアファイルを指定するために使用される

-`type`
目的：<source>タグで指定したメディアリソース（動画、音声、画像など）の MIME タイプを明示的に指定する
使用シーン：異なる形式のメディアファイルを提供して、ブラウザがサポートするものを選択するシナリオで type 属性を活用
メモ：MIME タイプ（インターネットでのデータ形式を表す標準形式）
