# 課題 1

- JavaScript の概要について説明してください。
- JavaScript がブラウザで果たす役割と可能な操作について具体例を挙げて説明してください。
- JavaScript における予約語の定義とその使用上の注意点を記載してください。
- セミコロンが JavaScript でどのような役割を果たしているかを説明してください。

【概要】
JavaScript は、動的な Web ページを作成するために開発されたプログラミング言語
現在では、フロントエンド（クライアントサイド）およびバックエンド（サーバーサイド）で幅広く使用されている
非同期処理やイベント駆動型プログラミングをサポートし、HTML や CSS と連携してインタラクティブなユーザー体験を提供することができる

【主なフレームワーク】
・jQuery
・React

【JS がブラウザで果たす役割とできること】

役割：ブラウザ上で動作し、Web ページの動的な更新やユーザーとの対話を可能にする
メモ：JavaScript における「ユーザーとの対話」とは、ユーザーの操作に応じて Web ページの動作を変えることを指す

・DOM 操作
→ JavaScript を使って、HTML の要素を動的に変更

・イベント処理
→ 　ユーザーの操作（クリックやキー入力）に応じて処理を実行

・非同期通信
→ Web サーバーと非同期にデータをやり取りし、ページをリロードせずに情報を更新

・データ保存
→ ユーザーの情報を保存し、再訪問時にデータを維持（ログイン情報やダークモードの設定など）

【予約語】
定義：JavaScript で特定の目的のために予約されているキーワード
使用上の注意点：
・予約語を変数名や関数名として使用しない
・近い名前を使用する場合、可読性を考慮する
・未来の予約語に注意

メモ：
「enum」「implements」「package」などのキーワードは、現在は使用されていなくても将来的に予約語として扱われる可能性がある

-- 代表的な予約語 --
var：変数を宣言する（非推奨）
let：ブロックスコープの変数宣言
const：定数の宣言
if / else：条件分岐
for / while：ループ処理
function：関数の定義
return：関数の戻り値を指定
class：クラスの定義
try / catch：例外処理

【セミコロンの役割】
役割：文の区切りを示し、誤動作を防ぐ

ブラウザが自動的に補完する「ASI (Automatic Semicolon Insertion)」という仕組みによって省略可能な場合もあるが
意図しない動作をすることがあるため、セミコロン（；）を使って明示的に記述するのが望ましい

バックエンド　 → node.js

# 課題 2

- strict mode（厳格モード）とは何か、また使用するメリットについて説明してください。

strict mode（厳格モード）とは、javascript のコードをより厳しくエラーチェックすることができる仕組み
通常はエラーとなっていなかったバグになりそうなコードに対して、エラーを表示することができる

【記述方法】
'use strict';

メモ：1 行目に書くと、全体に対して適用することができる（特定のスコープ内のみ適用も可）

-- メリット --
・コードの品質を向上させる
・エラーを未然に防ぐ

---

メモ：
【index1.js】
let a = 'Hello World';
console.log(a);

【出力】
Hello World

【index2.js】
a = 'Hello World';
console.log(a);

【出力】
Hello World

【index3.js】
'use strict';
a = "変数宣言の「let」が定義されていないね";
console.log(a);

【出力】
！エラー文！

# 課題 3

- JavaScript で使用できるコメントの記述方法を説明してください。

【行コメント　記述例】
console.log(1)
// console.log(2)

メモ：文頭に「//」の記述がある行をコメントアウトするので、コンソール画面には「１」だけ表示される

【ブロックコメント　記述例】
console.log(1)
/* console.log(2)
console.log(3) */

メモ：「/*」と「*/」で囲まれている部分をコメントアウトするので、コンソール画面には「１」だけ表示される
