## 課題１

以下の観点から CSS について説明してください。

- CSS とは何か

CSS（Cascading Style Sheets）は、ウェブページの見た目やレイアウトを定義するための言語です。HTML で作成されたウェブページの構造を装飾し、視覚的な要素を指定する

- CSS を使用する理由

1. ウェブページのデザインを好みにカスタマイズ
2. HTML とデザインを分離できる（ソースコードの可読性が向上）
3. 一貫性を保つ

- CSS が解決する問題

【HTML の問題点】

1. デザインの細かいカスタマイズができない（色、フォント、余白、レイアウトなど）
2. ページを視覚的に魅力的にする手段が不足している
3. 再利用性と効率性の欠如

HTML はウェブページの構造を定義するための言語であり、見た目を制御する機能が限定的ですが、
CSS は HTML の問題点を補うことができる。

## 課題 2

以下の項目について、具体的なコード例を含めながら説明してください。

【CSS の基本構成要素について】

- セレクター、プロパティ、値の役割と使用方法

  セレクター：HTML 要素を選択し、操作するための構文や規則のこと。記述例の「p」の部分を示す
  プロパティ：HTML 要素が持つ属性（属性値）や特性を指す。記述例「color」の部分を示す
  値の役割：プロパティにどのような動作やスタイルを適用するかを定義する記述例「red」の部分を示す

  値の使用方法：

  div {
  background-color: yellow;　<!-背景色を黄色に変更->
  margin: 10px;　<!-要素の外部に空白を 10px 追加->
  width: 50%;　<!-要素の横幅を 50%に指定する->
  }

【記述例】
p {
color: red;
}

- それぞれの要素の記述ルール

セレクター：冗長なセレクターを避ける、命名規則の統一、クラスセレクターを優先

プロパティ：0 には単位（px）を付けない、単位を統一、論理的な順序で記述（例：テキスト関連: font, line-height, color）

値：カラーコードの統一、小数点以下の値が 1 未満の場合、先頭のゼロを省略、値と単位の間にスペースを入れない

- 具体的な記述例

【記述例】
p {
color: red;
}

【宣言ブロックの書き方】

- 波括弧（{}）の使用方法

波括弧（{}）の中には 1 つ以上のプロパティとその値をコロン (:) で区切って書く

- 複数のプロパティを記述する際のルール

1. プロパティ名と値の間にはスペースを入れて見やすくする
2. 各宣言の末尾にはセミコロン (;) を付ける
3. ブロック内のプロパティは、適切にインデントを付ける

- 実際の記述例

【記述例】
h1 {
color: red;
font-size: 24px;
}

## 課題３

CSS セレクターの基本的な役割と重要性について説明してください。
以下の各セレクタータイプについて、説明してください。

役割：HTML内の特定の要素に対してスタイルを適用する
重要性：必要な要素だけにスタイルを適用することで、コードの簡潔さと効率を保てる

要素型セレクター：特定の HTML 要素にスタイルを適用する

【記述例】
h1 {
color: blue;
}

ID セレクター：特定の ID を持つ要素にスタイルを適用する

【記述例】
#header {
background-color: gray;
}

クラスセレクター：特定のクラスを持つ要素にスタイルを適用する

【記述例】
.button {
background-color: green;
color: white;

属性セレクター：特定の属性を持つ要素にスタイルを適用する

【記述例】
[type] {
border: 1px solid black;
}

& 入れ子セレクター：Sass や Less などのプリプロセッサで使用される構文で、親子関係を簡潔に記述できる

【記述例】
/_ Sass のコード _/
.button {
color: white;

/_ 入れ子のセレクター _/
&.primary {
background-color: blue;
}

&:hover {
background-color: darkblue;
}
}

---

メモ：「&」は「親セレクターそのもの」を意味する
プリプロセッサ（Preprocessor）：CSS や HTML、JavaScript などのコードを書く際に、記述をより効率的に行うための機能を提供するツール
→Sass：最も広く使用されている CSS プリプロセッサ。強力な機能と拡張性を持つ。
→Less：CSS プリプロセッサの中でもシンプルさを重視したツール

---

全称セレクター：すべての要素にスタイルを適用する

【記述例】

- * {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
  }

## 課題 4

- CSS を追加する 3 つの方法について、それぞれの特徴と使用場面を説明してください。
  【外部スタイルシート】
  ファイル形式: CSS コードを別ファイル（拡張子 .css）に保存。
  リンク方法: HTML ファイルの <head> 内で <link> タグを使用して読み込む。
  コードの分離: HTML と CSS を分離できるため、可読性とメンテナンス性が向上。

使用場面：複数ページのスタイルを統一する、規模が大きい Web サイトやプロジェクトで、CSS の管理を効率化

【内部スタイルシート】
記述場所: HTML ファイル内の <head> タグ内に <style> タグを使用して記述。
範囲: 当該 HTML ファイルのみに適用。
簡易性: 外部ファイルを作成しなくてもスタイルを記述可能。
メンテナンス性: 外部スタイルシートほどではないが、比較的管理が簡単。

使用場面：単一ページ限定のスタイルを設定、素早くプロトタイプを作成したいとき

【インラインスタイル】
記述場所: HTML 要素の style 属性に直接記述。
スコープ: その特定の要素にのみ適用。
高い優先度: 外部・内部スタイルシートより優先される。
可読性低下: HTML と CSS が混在し、コードが読みにくくなる。
再利用性なし: 他の要素に適用できない。

使用場面：一時的なデバッグや修正、特定の 1 つの要素にのみスタイルを適用したい場合


- 複数のスタイルシートが競合する場合の動作について説明してください。

スタイルシートの競合が発生した場合は「最後に読み込んだものが適用される」

【例】
p { color: blue; }
p { color: green; } /*  後に書いたのでこっちが適用される * /


メモ：カスケード順序とは、どのスタイルが優先されるかを決めるルール
カスケード順序

1. インラインスタイル
2. 外部および内部スタイルシート
3. ブラウザのデフォルトスタイル
