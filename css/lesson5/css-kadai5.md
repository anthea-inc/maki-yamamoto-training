## 課題１

- 以下の CSS プロパティについて調査し、それぞれの役割を説明してください。

padding
役割：要素の内側のスペースを定義する

padding-top
役割：要素の内部の上部に余白を追加

padding-right
役割：要素の内部の右側に余白を追加

padding-bottom
役割：要素の内部の下部に余白を追加

padding-left
役割：要素の内部の左側に余白を追加

メモ
【マージンとパディングの違い】
マージン：要素の外部に余白を作る
→ 要素と隣接する要素との間隔を調整する

パディング：要素の内部に余白を作る
→ 　要素の内容（テキストや画像など）とボーダーの間隔を調整する
