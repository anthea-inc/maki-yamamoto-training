## 課題１

以下の点について、ボックスモデルを調査し、説明してください。

- ボックスモデルとは何か
  要素同士の間隔やレイアウトの調整を正確に行うための基本的な仕組みのこと
  各ボックスは次の 4 つの領域で構成される

1. コンテンツ（Content）
   → 要素の中身が表示される領域

2. パディング（Padding）
   → コンテンツとボックスの境界線（ボーダー）の間の余白を表す

3. ボーダー（Border）
   → パディングの外側にある枠線

4. マージン（Margin）
   → ボックスの最も外側に位置する領域で、他のボックスとの間隔（余白）を定義する

---

- 以下の各構成要素の特徴

- margin
  特徴：マージンは上下の値が自動的に結合される「マージンの相殺（Margin Collapse）」という性質がある

- border
  特徴：ボーダーは視覚的にボックスの境界を定義する役割を持つ

- padding
  特徴：パディング値が大きいほど、コンテンツとボーダーの距離が広がる

- content
  特徴：ボックスの中身（テキストや画像など）が配置される領域。
  　　　幅（width）や高さ（height）を指定することでサイズを制御できる。

---

メモ：各要素の相関関係
ボックスの外側から内側に向かって順に配置される

1. Margin
2. Border
3. Padding
4. Content
