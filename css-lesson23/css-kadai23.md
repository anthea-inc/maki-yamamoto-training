## 課題１

- 以下の CSS 値関数について調査し、それぞれの役割を説明してください。

- calc()
  役割：CSS で動的な値を計算する
  記述例：calc(16px + 1vw);
  ↑ 基準値として固定の 16px に加え、ビューポート幅の 1%の値を足した合計 ↑
  ↑ この値は動的で、画面のサイズ（ビューポート幅）が変わると 1vw の値が変わるため、それに応じて計算結果も変化する ↑

メモ：
数値や単位の異なる値を組み合わせることができる
四則演算（+, -, \*, /）をサポート

- max()
  役割：複数の値の中で最大値を選択する
  記述例：値が最も大きいものを適用する
  width: max(500px, 80%);

- min()
  役割：複数の値の中で最小値を選択する
  記述例：値が最も小さいものを適用する
  width: min(200px, 50%);

## 課題 2

- 上記で挙げられていない CSS 値関数を 3 つ調査し、以下の項目を含めて説明してください。

- CSS 値関数の名前と基本的な機能
- どのような場面で活用できるか

- url()
  基本機能：外部リソース（画像やフォントなど）の場所を指定する
  活用場面：背景画像やカスタムフォントの指定など

- linear-gradient()
  基本機能：線形グラデーションを生成する
  活用場面：背景のグラデーション、透明なグラデーションの作成など

- rgb(), rgba()
  基本機能：赤・緑・青の値で色を指定する（rgba() は透明度（アルファ値）も追加で指定可能）
  活用場面：カラフルな要素の作成、シャドウの色付けなど
