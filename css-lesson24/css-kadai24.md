## 課題１

- CSS 変数の定義方法と使用方法について、基本構文を示しながら説明してください。
- CSS 変数を実務で活用することで得られるメリットについて考察してください。
- 
CSS変数（カスタムプロパティ）は、再利用可能な値をCSS内で定義できる仕組みのこと

CSS 変数の定義方法：「--変数名：値；」
CSS変数は、通常 :root に定義することで、グローバルに適用できる（特定の要素にスコープを限定して定義することも可）

使用方法：「プロパティ：var(--変数名);」

実務で活用するメリット：
・再利用性の向上
　 → 一度変数を定義すれば、異なるスタイルシートやコンポーネントでも簡単に再利用できる
・メンテナンスが容易
　 → 変数を使用すると、変更点を最小限に抑えつつ全体のデザインを調整できる

## 課題 2

- CSS 変数におけるグローバルスコープとローカルスコープの違いについて説明してください
- グローバルスコープを利用する際の主なメリットを挙げ、それがどのような場面で有用かを説明してください。
- グローバルスコープを使用する場合における実装上の注意点や課題についても、具体例を挙げて説明してください。
- CSS 変数のオーバーライドについて、実装時の注意点を含めて説明してください。

【グローバルスコープとローカルスコープの違い】

- グローバルスコープ
  :root セレクタに定義された変数は、ページ全体で有効になる
  すべての要素がこの変数を使用できる

- ローカルスコープ
  特定の要素に対して定義された変数は、その要素とその子要素にのみ適用される

【グローバルスコープのメリットと有用な場面】
・一元管理が容易
　 → 「:root」に定義することで、全体のスタイルガイドを統一し、変更が一箇所で済む
・再利用性が高い
　 → サイト全体のカラーパレットやフォントサイズを統一し、異なるページでも同じ変数を活用できる

【グローバルスコープの実装上の注意点や課題】
グローバルスコープの CSS の実装では、意図しないスタイルの上書きや衝突が起こりやすいため、適切なスコープ管理が重要である

注意点１：
グローバルに適用されるセレクタ（例: h1 や p）が全体に影響し、意図しないスタイルになる
対策１：
セレクタの範囲を特定のコンテナに絞る

注意点２：
CSS のグローバルセレクタ（例: \* や body）や、汎用的なクラス名（例: .button, .container）は、他のスタイルやコンポーネントに影響を及ぼす可能性がある
対策２：
クラス名や ID をモジュールやプロジェクトに固有のものにする

【CSS 変数のオーバーライドの注意点】
注意点１：
変数が未定義の場合、利用箇所でフォールバックを指定しないとスタイルが崩れる
対策１：
var(--変数, フォールバック値) を活用

注意点２：スコープ（適用範囲）に注意する
「.theme-dark」が適用されていない要素では「--primary-color」は blue のまま

:root {
--primary-color: blue;
}

.theme-dark {
--primary-color: black;
}

## 課題 3

- CSS 変数を@property で登録・活用する方法について、以下の要素を含むコード例とともに説明してください。
  - 構文
  - 型定義
  - 初期値の設定
  - @property が特に効果を発揮するケースとそのメリットを具体的に教えてください。

CSS の @property ルールを使うことで、カスタムプロパティ（CSS 変数）に型、安全なアニメーション、初期値を設定できる

【構文】
@property --my-color {　/_ カスタムプロパティ（CSS 変数）"--my-color" を定義 _/
syntax: "<color>";　/_ syntax: 変数の値として許可するデータ型を指定（ここでは <color> 型） _/
inherits: false;　/_ inherits: 継承の可否を指定（false にすると親要素から継承しない） _/
initial-value: #ff0000;　/_ initial-value: 初期値を指定（ここでは赤 "#ff0000"） _/
}
【指定可能な型の一例と定義方法】

定義方法：
「@property」では、syntax で CSS の型を定義する

記述例：
syntax: "<color>";

↓ 指定可能な型の一例 ↓

型：<color>
説明：色
例：red, #ff0000, rgb(255, 0, 0)

型：<length>
説明：長さ
例：10px, 2rem

型：<percentage>
説明：割合
例：50%

型：<number>
説明：数値
例：1, 2.5

型：<angle>
説明：角度
例：45deg, 1rad

【初期値の設定：initial-value】
@property --size {
syntax: "<length>";
inherits: false;
initial-value: 10px;
}

【「@property」が特に効果を発揮するケースとそのメリット】
効果を発揮するケース
・CSS 変数を活用し、色やサイズの変更をスムーズに適用
・JavaScript を使わずにカスタムアニメーションを実装
・複雑なホバーエフェクトやスクロールに応じたスタイルの変化

メリット
・CSS のみで動的なスタイル変更を実現可能
・CSS 変数のアニメーションをサポートし、より柔軟なデザインが可能
