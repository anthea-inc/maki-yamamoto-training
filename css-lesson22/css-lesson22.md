## 課題１

- 以下の点について調査し、説明してください。

CSS における!important の役割と基本的な使用方法
スタイル適用の優先順位における!important の影響

役割：通常の CSS ルールやスタイル適用の計算（CSS のカスケーディング）を無視して、指定したスタイルを最優先で適用する
使用方法：
.element {
color: red !important; /_ この色指定は他のルールを上書きする _/
font-size: 16px;
}

【スタイル適用の優先順位における!important の影響】
「!important」は、CSS の優先順位を強制的に引き上げる特性を持っている。
通常、スタイル適用の優先順位はセレクターの詳細度や記述の順序（後勝ち）によって決まるが、「!important」を使用すると、詳細度を無視してそのスタイルを最優先で適用させることができる

## 課題 2

- 以下の点について調査し、説明してください。

!important の使用が推奨されない理由
!important の多用によって発生する具体的な問題点

- CSS の優先順位（カスケード）を壊し、コードの予測可能性が低下する
- 構造が複雑化するため、スタイルの競合が増加する
- スタイルの依存関係が複雑化するため、他のスタイルを修正したときに、「!important」の影響を受ける箇所を追跡するのが困難になる

---

メモ：
競合する「!important」の解決
→ 複数の「!important」が競合した場合、通常の詳細度と定義順序が適用される
