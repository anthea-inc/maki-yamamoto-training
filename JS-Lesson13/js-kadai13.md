## 課題 1

- スコープの基本的な概念と、その役割について説明してください。

スコープとは「変数や関数がアクセスできる範囲」のことを指す
変数や関数のスコープがどこまで有効なのかを明確にすることで、予期しないバグを防ぎ、コードの可読性や保守性を向上させる

-- 役割 --
・必要な範囲内でのみ変数を使用可能にすることで、意図しない変更を防ぐ
・グローバル変数を増やしすぎると名前の競合が起こる可能性があるため、スコープを適切に管理することで競合を回避できる
・関数内で定義された変数は関数が終了するとメモリから解放されるため、メモリの無駄遣いを防げる

JavaScript には主に以下の 3 つのスコープがある
・グローバルスコープ
→ スクリプト全体でアクセス可能なスコープ

・ローカルスコープ
→ 関数内で定義された変数は、その関数内でのみ有効

・ブロックスコープ
→ {} で囲まれたブロック内でのみ有効なスコープ

- グローバルスコープ/関数スコープ/ブロックスコープの特徴や用途を整理し、具体的なコード例を交えて解説してください。

-- グローバルスコープ --

特徴
・スクリプト全体でアクセス可能な変数
・window（ブラウザ環境）や globalThis によって明示的にアクセスできる
メモ：Node.js 環境では window オブジェクトが存在しない

用途
・アプリ全体で共有する定数（環境設定など）
・デバッグ時に変数を簡単に確認する

【index.js】
var global1 = "I am global"; // グローバルスコープ　 globalThis 適用範囲内
let global2 = "I am also global"; // グローバルスコープ　 globalThis 適用範囲外

function showGlobal() {
console.log(global1);
console.log(global2);
}

showGlobal();

console.log(global2);

/_
・var で宣言した変数は globalThis に追加される
・let や const で宣言した変数は globalThis に追加されない
・showGlobal(); を実行すると、global1 と global2 の値がコンソールに表示される
_/

【出力結果】
I am global
I am also global
I am also global

-- 関数スコープ --

特徴
・関数内で宣言された変数は、その関数内でのみアクセス可能
・var は関数スコープを持つ
・関数が終了すると、変数は破棄される

用途
・関数内でのみ使う変数を管理する
・外部に影響を与えたくないデータを扱う

【index.js】
function myFunction() {
var a = "I am inside a function"; // 関数スコープの変数
console.log(a);
}

myFunction();

console.log(a);

【出力結果】
ReferenceError: a is not defined

メモ：変数「a」関数内でしか使えないため、関数外でアクセスするとエラーになる
・

-- ブロックスコープ --

特徴
・let と const はブロックスコープを持つ
・{}（ブロック）の中で宣言された変数は、そのブロック内でのみ有効
・var にはブロックスコープがないため注意が必要

用途
・ループや条件分岐でのみ使う変数を管理する
・意図しない変数の上書きを防ぐ

【index.js】-- let と const のブロックスコープ --
if (true) {
let b = "I exist inside this block";
console.log(b);
}

console.log(b);

【出力結果】
ReferenceError: b is not defined

メモ：
・ 変数「b」は if ブロック内でのみ有効なので、外からアクセスするとエラーになる

【index.js】-- var はブロックスコープを持たない --
if (true) {
var c = "I am function scoped";
}

console.log(c); //　意図しない動作

【出力結果】
I am function scoped

メモ：
・var はブロックスコープを持たないため、if ブロックを抜けても 変数「c」にアクセスできる
・if 文は単なるブロック（{}）であり、関数ではない

- スコープチェーンの概念について、仕組みと実際の動作を説明してください。

スコープチェーン（Scope Chain） は、変数を検索する仕組みのことを指す
変数の可視性や参照の仕方を理解する上で非常に重要

1.現在のスコープで変数を探す 2.見つからなければ、一つ上のスコープ（親スコープ）に移動する 3.最終的に、グローバルスコープに到達する 4.それでも見つからなければ、ReferenceError が発生する

【index.js】
let global = "Global"; // グローバルスコープ

function outer() {
let outer = "Outer"; // outer のスコープ

function inner() {
let inner = "Inner"; // inner のスコープ
console.log(inner); // "Inner"（自身のスコープ）
console.log(outer); // "Outer"（スコープチェーンで親を参照）
console.log(global); // "Global"（スコープチェーンでさらに親を参照）
}

inner();
}

outer();

【出力結果】
Inner
Outer
Global

## 課題 2

- 関数宣言における巻き上げの概念を説明し、コードがどのような順序で解釈されるかを具体例を用いて明確に示してください。

巻き上げ（Hoisting）とは、JavaScript がコードを実行する前に、関数や変数の「宣言」を自動的にコードの先頭に持ってくる仕組みのこと
これにより、コードの見た目とは異なる順序で解釈されることがある
関数宣言は巻き上げの対象になるが、関数式は巻き上げの対象ではない

【index.js】
greet(); // "Hello, World!" と出力される

function greet() {
console.log("Hello, World!");
}

【出力結果】
Hello, World!

【index.js】-- 実際の解釈イメージ（巻き上げ後） --
function greet() { // 関数が先に登録される
console.log("Hello, World!");
}

greet(); // ここで関数を実行できる

【出力結果】
Hello, World!

## 課題 3

- クロージャーとは何か、その定義と内部でどのようにスコープが保持されるかについて解説してください。

クロージャー（Closure） とは、外側の関数のスコープ内で定義された変数を、外側の関数の実行が終了した後も保持し続ける関数のこと
関数が定義されたスコープの変数を「記憶」し、後でその変数を参照・変更できる

-- クロージャーがスコープを保持する仕組み --
スコープチェーンとガベージコレクションの性質に基づいている

・関数が作成されたときに、その関数がどのスコープ内で定義されたのかを記録する
・内部関数（クロージャー）が外部関数の変数を参照している限り、その変数はガベージコレクションの対象とならず、メモリ上に残り続ける
・内部関数が外部関数のスコープにアクセスできる仕組み（スコープチェーン）により、クロージャーは外部関数の変数を参照し続けることができる

メモ：
ガベージコレクションとは、プログラムが不要になったメモリを自動的に解放する仕組みのこと
JavaScript では、メモリ管理を手動で行う必要はなく、ガベージコレクションが不要になったオブジェクトを検出し、解放する

- クロージャーを利用した具体的なコード例を提示し、クロージャーがもたらす利点について説明してください。

-- クロージャーの利点 --
・外部から直接アクセスできない変数（プライベート変数）を作成する。これにより、データを適切に隠蔽し、安全に管理できる
・一度関数が実行された後でも変数の値を保持するため、状態を管理するのに適している
・グローバル変数の汚染防止ができる

【index.js】
function counter() {
let count = 0; //　関数スコープ内の変数

return function () {
//　内部関数（クロージャー）
count++; //　外部関数の変数を更新
return count; //　現在の count を返す
};
}

const result = counter(); //　 counter() を呼び出してクロージャーを取得
console.log(result());
console.log(result());
console.log(result());

/_
・count は counter() 内で定義された変数なので、通常なら counter() が実行された後に消えてしまうはずだが
クロージャー によって count が保持され続ける
_/

【出力結果】
1
2
3
