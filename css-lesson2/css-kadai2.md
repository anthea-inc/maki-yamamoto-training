以下の CSS プロパティについて調査し、それぞれの役割を説明してください。

background-color
役割：要素の背景色を指定する

background-image
役割：要素の背景として画像やパターンを設定する

background-repeat
役割：要素の背景画像がどのように繰り返されるか（または繰り返されないか）を指定する

repeat-x
役割：背景画像を 水平方向（X 軸）に繰り返す
メモ：background-repeat プロパティの値の一つ

repeat
役割：背景画像を 水平方向（X 軸）と垂直方向（Y 軸）の両方に繰り返す
メモ：background-repeat プロパティの値の一つ

no-repeat
役割：背景画像を繰り返さずに 1 回だけ表示する
メモ：background-repeat プロパティの値の一つ

background-position
役割：要素の背景画像の位置を指定する
メモ：left, center, right (水平方向の位置)
　　　 top, center, bottom (垂直方向の位置)

background-attachment
役割：背景画像がスクロールやその他の要素の動きに対してどのように振る舞うかを制御する

background
役割：要素の背景に関する複数のプロパティを一括で指定する
