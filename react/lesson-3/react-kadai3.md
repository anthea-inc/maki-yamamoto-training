## 課題 1

- DOM（Document Object Model）とは何かを説明してください。

HTML や XML のドキュメントをオブジェクトとして扱うための仕組みで、これを「ツリー構造」として表現する。
このツリー構造は、ドキュメントの各要素やテキストデータを階層的に組み合わせて表すもので、最上位には「Document ノード」が存在し、その下にさまざまな要素やテキストノードが階層的につながっている。

【index.html】

<!DOCTYPE html>
<html>
  <head>
    <title>タイトル</title>
  </head>
  <body>
    <h1>見出し</h1>
    <p>段落</p>
  </body>
</html>

- DOM がブラウザ上での操作や画面表示において重要な役割を果たす理由を、具体例を挙げながら説明してください。

Web ページを作成するとき、HTML を使用してコンテンツを作成する。
しかし、HTML だけでは静的な構造しか表現ができないため、動的ページを作りたい場合は JavaScript から DOM のインターフェースを使用して操作する。

-- DOM の役割まとめ --
表示：HTML を DOM に変換して、ブラウザに描画させる
操作：JavaScript などから DOM を使って、要素の表示・非表示・スタイルの変更を行う
イベント処理：ユーザーのアクション（クリック・入力など）を DOM のイベントとして受け取る
構造の更新：ノードの追加・削除・並び替えなど、ページ構造自体を変更可能

メモ：
DOM の問題点
従来の DOM 操作（Vanilla JS、jQuery）は、要素の変更が発生するごとに DOM の反映が行われる
しかし、DOM の更新は動作が重く、大規模になるとパフォーマンスの低下に繋がる

この問題を解決するために生まれたものが仮想 DOM である

## 課題２

- 仮想 DOM（Virtual DOM）とは何かを説明し、通常の DOM との違いを明確にまとめてください。

実際の DOM の軽量なコピー（オブジェクト表現）であり、JavaScript のオブジェクトとしてメモリ上に保持されるツリー構造

構成
通常の DOM：ブラウザが保持する実際の HTML 要素ツリー
仮想 DOM：JavaScript オブジェクトとしての仮想的なツリー

更新方法
通常の DOM：DOM API を直接操作
仮想 DOM：仮想 DOM 上で変更を反映後、差分を検出して最小限で更新

パフォーマンス
通常の DOM：頻繁に変更が行われることで再描画コストが高くなる
仮想 DOM：差分のみを更新する

利用する目的
通常の DOM：標準的なブラウザの UI 描画
仮想 DOM：UI の再描画を効率化するために使用（主に React など）

これは主に UI ライブラリやフレームワーク（例：React）で使用され、パフォーマンスの最適化を目的としている

メモ：仮想 DOM は、頻繁に再描画する必要があるときに適しているんだなぁ

- React が仮想 DOM を採用している理由を述べ、それがもたらす具体的なメリットについて説明してください。

React は、状態の変化に応じて UI を効率的に更新する必要があるという前提のもと設計されている。
この目的を実現するために、React は変更を検知した際に「変更前の仮想 DOM」と「変更後の仮想 DOM」の差分を比較し、必要な箇所のみを実 DOM に反映する。

これにより、今まで jQuery で命令的に一部の要素を変更していたような実装を、状態に応じた UI を宣言的に記述する形へと転換することが可能となる。

メモ：
jQuery は、ブラウザで表示されている HTML(=実 DOM)を操作する
React は、先に仮想 DOM を作り、実 DOM との差分を計算し、差分だけを HTML に適用する
